# أثر تذكير السلة المتروكة على نسبة إتمام الشراء.

# الاسم : Bassam Faisal Alzahrani
# الجهة أو المنتج: متجر إلكتروني.
# 1. السؤال و الفرضية :
 القرار: إطلاق ميزة إرسال تذكير بالسلة المتروكة للعملاء أو عدم إطلاقها.
 الفرضية: إذا أرسلنا إشعار تذكير للعملاء الذين تركوا منتجات في السلة، فسوف تزيد نسبة إتمام الشراء، لأن التذكير يعيد جذب انتباههم لإكمال الطلب.
 ما الذي يجعلنا نغير رأينا: إذا لم تكن هناك زيادة ذات دلالة إحصائية في المبيعات، أو إذا ارتفعت نسبة انزعاج العملاء (إلغاء الاشتراك من الرسائل) بشكل يضر بالمتجر. 

# 2. التصميم :
 وحدة العشوأة: المستخدم (User).
 نسبة التوزيع: 50% للنسخة A (بدون تذكير) و 50% للنسخة B (مع تذكير).
 المقياس الرئيسي: نسبة إتمام الشراء (Conversion Rate).
 مقاييس ثانوية: متوسط قيمة الطلب (Average Order Value)، والوقت المستغرق لإتمام الطلب.
 مقاييس الحماية: نسبة إلغاء الاشتراك من الرسائل الترويجية أو الإشعارات (Unsubscribe Rate). 
 شرط SUTVA: يتحقق الشرط، لأن إرسال تذكير لمستخدم معين لا يؤثر على قرار مستخدم آخر بإتمام الشراء.
